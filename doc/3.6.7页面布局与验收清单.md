# 3.6.7 页面布局与验收清单

更新于 2026-10-28，分支 `lylighte/feat-frontend`。本文件定义本轮各页面的内容顺序、容器规则与人工验收入口。工程结果见[实施计划第 12.11—12.13 节](前端整理后续实施计划.md)，通用规则见[前端交互与视觉设计约定](前端交互与视觉设计约定.md)。**视觉由用户验收，本清单不代填通过。**

主标题色彩、首页媒体状态位置、个人资料邮箱行及长公告表单高度的第 8 节四项已由用户勾选通过。后续新增“副标题影响渐变范围”和“更长预览撑高公告窗口”反馈，已完成工程补正，第 9 节仍待用户复验；既有勾选原样保留。OAuth 正常授权页无有效请求验证另列验收例外。最新反馈与工程记录见实施计划第 12.19—12.22 节。

## 1 本批目标与边界

本批在既有字段、权限和流程上统一页面骨架，使标题、说明、筛选、内容和动作在窄视口仍可辨认、可达。先完成普通页屏幕顶栏，再统一标题与容器，最后核对各页内容布局。没有借布局修改请求参数、字段验证、保存时机、材质归属或后端权限。

33 条路由包含两个容器，以及创建／编辑、通知详情复用的页面，不是 33 套不同实现。下表每条均有归属；无需改结构的页面明确保留现有内容顺序，不能为了产生 diff 重排已经合理的表单。

## 2 共同规则

- 普通页顶栏固定在屏幕顶部，流中保留同高占位。宽度来自占位容器，沿用滚动槽；不手算滚动条或逐帧监听滚动。首页顶栏仍流式，认证页没有顶栏占位。
- PageHeader 按旧版对照恢复主标题 32px／400（正常字重）／1.6 和副标题 16px／1.6，标题到副标题间距 8px；用户页和管理页主标题共用 135°、`--color-heading` 到 `--color-primary` 的文字渐变，宽度跟随标题自身、最多占内容区全宽，不随副标题拉伸；副标题使用 `--color-text-light`，图标可选。返回入口、对象元信息、主操作和整行筛选工具栏各有位置。旧用户页头及其全局选择器已删除。
- PageContainer 的 form／editor／wide／gallery 分别对应 900／1000／1200px／可用全宽。普通页侧距与容器上下留白分别为共享 20px；内容中的间距继续引用既有 8／12／16／20／24px 来源或标准 utility。
- 设置分组、表格和详情卡片允许收缩，长文本换行；宽表只在表格内部滚动，不裁掉列来伪装适配。分页、筛选、分组标题与保存按钮可换行，动作及标签仍归原分组。
- 卡片错峰和既有头像 hover 保留；布局调整不重播内容入场，也不重建列表／详情。UI 测试不能证明真实像素效果。
- 认证卡保留 440px、28px 标题的具名例外；授权面板沿用标准 max-w-3xl；资料内层 600px 和预览尺寸属于局部约束。首页 hero、富文本标题和材质画廊不是普通编辑表单。

## 4 本轮有针对性的内容补正

首页媒体将动作区放在标题下独立整行，避免中间宽度里标题、dirty 和多按钮互相挤压；四处公共页头移除重复动作布局包装，继续由同一 ActionBar 处理。设置卡片的标题／dirty／保存行允许换行，不重新分配保存归属。

UiCard、表单内容和选项卡建立 min-width:0 边界；表格及数值控件受所在容器最大宽限制。UiSegmented 沿用 Element Plus 的原生换行，加上行间距及最大宽；分页允许换行，并补齐上一页／下一页的可访问名称。不改变筛选取值或分页 limit。

仪表盘统计改为可收缩等宽网格，资料页长账号信息换行、窄屏标签上下排列，Fallback 的探测行和白名单／端点网格允许收缩与换行。通知长标题和正文换行，图片限于正文宽度，代码／表格在正文内部滚动，长外链按钮可换行；不改 Markdown 清洗和链接策略。

认证字号变量使用 Tailwind 显式 length 类型；构建产物核对发现不加类型时会被解释成颜色，已修正。阴影变量经构建产物确认用于 box-shadow，避免重复此前渐变变量放错属性的回归。

## 5 人工验收清单

以下全部待用户填写；可按上表逐页或同类页面分组复验。建议包含桌面、导航断点两侧、360px 左右窄屏及短窗口；这些是本轮布局复验，不等于手机软键盘／触摸／预览专项已经完成。

- [x] 长页顶栏在屏幕顶部，正文占位及锚点／聚焦可见；中段开关浮层后顶栏、滚动槽和滚动位置稳定。
- [x] 普通页标题与副标题统一，图标可选；四类容器与认证／授权／首页例外符合内容用途。
- [x] 首页媒体、角色管理、通知和管理列表的标题、状态、工具栏不互相遮挡；按钮未裁切，能正常换行。
- [x] 窄屏表格可在内部左右浏览，没有整页横向溢出；空表、有数据、长名称和邮箱均检查。
- [x] 表单标签、说明、错误、dirty 与提交动作可扫描；资料窄屏标签上下排列，设置保存范围未变。
- [x] 卡片静态预览、逐卡错峰、角色快捷按钮和减少动态效果无回退；公共库添加不冒泡。
- [x] 深浅主题、长通知正文／图片／代码／表格、身份及应用长 ID 可读，焦点和关闭入口可达。
