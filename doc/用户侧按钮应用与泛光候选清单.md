# 用户侧按钮应用与泛光候选清单

更新日期：2026-10-28。分支：`lylighte/feat-frontend`。本清单记录 3.6.5 反馈修正后的源码现状，用户已选择第 4 节 A、B 两组，工程实现完成、视觉待复验；C、D、E 未启用推广。

## 1 范围与结论

覆盖公共库、首页、认证／授权、个人仪表盘、通知、衣柜、角色、资料、关联身份、个人第三方应用及其共用组件。扫描 61 个 Vue 文件，其中 33 个文件含下表统计的 103 处按钮模板声明：55 处 UiButton、41 处 el-button、7 处原生 button。启动器链接迁为 UiButton 的 tag=a，仍是可拖拽原生链接。

这些数字是静态声明数，循环、权限和流程状态会改变实际可见数量。普通链接、菜单项、互斥选择、开关、整卡打开入口不按命令按钮计数；ElMessageBox 动态生成的确认按钮另行说明。管理业务页面不在本清单内；冻结的两个 Webhook 编辑组件未读取、未修改，不计入覆盖。

当前共有 31 处静态按钮声明启用共享泛光：保留原有公共库两处，本轮为 A、B 新增 29 处；其中成功绿 2 处、导入橙 1 处，其余 28 处使用主色蓝。按钮自身不位移，卡片整体上浮与阴影保留。数据模型、API、权限和写入时机均无变更。

## 5 工程验证与人工复验

上一批双向过冲与 tooltip 修正通过相关 105 项回归。本轮 A／B 推广完成全量前端验证：其余 64 个文件、756 项通过，UiPrimitives 的五条新增断言将“无 transform”的预期由空字符串改为计算值 none 后，定向 35 项全部通过，合计覆盖 65 个文件、791 项。构建含类型检查、改动源码 ESLint／Prettier 通过。新增断言覆盖五种 tone 的色源、默认不启用泛光、禁用／加载阻止重复命令，以及启动器链接 href、可拖拽和取消默认跳转的事件透传。API、权限、名称草稿和写入锁不变。

源码和 DOM 检查不能证明浏览器逐帧观感。以下由用户复验，不由代理勾选：

- [ ] 角色三个快捷按钮图标旋转进入有过冲，鼠标移出及键盘焦点离开后文字回位也过冲恢复；快速进出不留下文字／图标叠层或可见 tooltip。
- [ ] 角色按钮等宽、图标居中，可用项／禁用／写入保护及 Enter／Space 执行不变；减少动态效果下即时切换。
