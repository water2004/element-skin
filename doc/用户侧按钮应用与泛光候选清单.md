# 用户侧按钮应用与泛光候选清单

更新日期：2026-10-28。分支：`lylighte/feat-frontend`。本清单记录 3.6.5 反馈修正后的源码现状，供选择后续泛光入口；候选不是已经批准或启用的样式。

## 1 范围与结论

覆盖公共库、首页、认证／授权、个人仪表盘、通知、衣柜、角色、资料、关联身份、个人第三方应用及其共用组件。扫描 61 个 Vue 文件，其中 33 个文件含下表统计的 103 处按钮模板声明：36 处 UiButton、59 处 el-button、7 处原生 button、1 处模拟按钮的 a。

这些数字是静态声明数，循环、权限和流程状态会改变实际可见数量。普通链接、菜单项、互斥选择、开关、整卡打开入口不按命令按钮计数；ElMessageBox 动态生成的确认按钮另行说明。管理业务页面不在本清单内；冻结的两个 Webhook 编辑组件未读取、未修改，不计入覆盖。

当前共享泛光仅启用于公共库卡片及详情的两个“添加到衣柜”入口。本轮取消其自身上移，保留卡片整体上浮和原泛光；其余候选没有增加泛光。数据模型、API、权限和写入时机均无变更。

## 2 反馈能力与边界

| 能力           | 当前实现                                                                         | 本轮结果与边界                                                                                                                               |
| -------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 主次／语义     | UiButton 的 variant／tone；旧入口仍直接使用 el-button 的 type／plain／link／text | 不能把所有 primary 外观视作同一重要程度，也不在本轮批量迁移。                                                                                |
| 泛光           | UiButton 的 hover-effect，默认关闭                                               | 使用 `--shadow-button-hover`：`0 4px 12px`、主色 28%。当前两处均为蓝色主动作。                                                               |
| 泛光触发       | 支持 hover 的设备，且按钮非 disabled／loading                                    | 键盘保留独立 focus-visible 轮廓，触屏不要求有持续 hover。静态阴影不随减少动态效果消失，过渡时长随偏好归零。                                  |
| 按钮位移       | 共享 hover-effect 不再包含 transform                                             | 公共库按钮不独立上移，随 PreviewCard 上浮仍保留。                                                                                            |
| 卡片上浮／阴影 | PreviewCard 的整体悬浮效果                                                       | 本轮未改其源码，不由取消按钮微动推导为取消卡片动效。                                                                                         |
| 图标切换       | 三个个人角色快捷入口使用 swap-icon                                               | 头像 → Setting，皮肤／披风 → Close；移除三个可见 tooltip，保留完整 aria-label。                                                              |
| 双向过冲       | 文字上移缩小、图标从下方 -90° 旋转进入                                           | 对照旧基线 `39f4bb1`，transform 为 300ms、`cubic-bezier(0.34, 1.56, 0.64, 1)`，opacity 为 300ms ease。常态声明过渡，进入与退出回位均有回弹。 |
| 退出与禁用     | hover 与 focus-visible 均退出才回位；禁用／加载不显示切换目标                    | 完整文案占位及点击区不变。减少动态效果时即时切换，不改变命令。                                                                               |
| 首页例外       | HomeView 原生玻璃按钮自己的视觉规则                                              | 仍有 hover／focus 的共享 2px 上移，未启用 UiButton 泛光；本轮只处理指定公共库，不宣称全站按钮位移清零。                                      |
| 其他阴影       | 卡片、头像、弹层及可选权限标签存在各自阴影                                       | 它们不算命令按钮的泛光，不能通过全局选择器一起修改。                                                                                         |

## 4 建议的选择范围

以下仅为建议，当前不改调用方。优先按动作角色选择，不能按组件名／蓝色外观一次全开。

| 候选分组         | 具体范围                                                                                                                                                           | 建议                                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------- |
| A 主要提交／创建 | 上传纹理、确认上传、新建／创建角色、确认导入、建立绑定、应用到角色、保存资料／确认重设邮箱、添加身份／连接、申请应用及主要表单提交、保存名称、登录／注册／重置密码 | 优先候选。原 el-button 若采用共享泛光，应先迁入 UiButton 并保留行为，不复制阴影 CSS。分步“下一步”可以保持次于最终提交。 |
| B 次要业务动作   | 绑定正版入口、导入入口、设为头像、同步正版、重设邮箱入口、重新连接、应用管理、启动器复制                                                                           | 单独选择。若 success／warning 也启用，需要先确定对应语义色；当前蓝色泛光变量不能直接代表所有 tone。                     |
| C 工具／导航     | 刷新／重载、搜索、分页、返回／取消／关闭、Hash 复制、顶栏通知／主题、账号导航、发送验证码、通知外链、设备查询                                                      | 建议保持原有悬浮和焦点反馈，避免每处都强调。重新加载配置有明确语义也不等于必须泛光。                                    |
| D 破坏性动作     | 删除纹理／角色／身份／应用、注销账号、撤销授权、解除绑定、清除皮肤／披风                                                                                           | 建议暂不增加；保持 warning／danger 语义和已有确认。若用户决定采用，需逐项明确颜色、强度及保护状态。                     |
| E 独立视觉场景   | 首页玻璃按钮、OAuth 授权同意／拒绝、权限选择标签                                                                                                                   | 分开讨论。首页避免叠加背景效果；授权确认不能仅为统一外观加大同意侧的视觉诱导。                                          |

泛光强度先沿用现有值，不额外恢复旧渐变或按钮位移；禁用／加载不发光。后续新增入口需检查深浅色、鼠标／键盘／触屏及减少动态效果，确认焦点轮廓未被阴影替代。

## 5 工程验证与人工复验

本轮三个相关测试文件、105 项通过；前端构建含类型检查、改动文件 ESLint／Prettier 通过。新增回归核对进入／退出使用同一过冲过渡、键盘焦点回位、禁用恢复；角色权限回归核对无 tooltip、完整动作名、执行次数及不冒泡。未改变 API、权限、名称草稿或写入锁。

源码和 DOM 检查不能证明浏览器逐帧观感。以下由用户复验，不由代理勾选：

- [ ] 角色三个快捷按钮图标旋转进入有过冲，鼠标移出及键盘焦点离开后文字回位也过冲恢复；快速进出不留下文字／图标叠层或可见 tooltip。
- [ ] 角色按钮等宽、图标居中，可用项／禁用／写入保护及 Enter／Space 执行不变；减少动态效果下即时切换。
- [ ] 公共库卡片仍上浮、阴影正常，添加按钮随整卡移动但无第二次独立上移；卡片及详情的添加泛光均保留。
- [ ] 从第 4 节选择新增泛光入口；未选择前维持现有两处启用范围。

通知空态刷新、第三方应用容器收缩、字段未保存重复提示、页头色彩／邮箱行／长公告高度、上传默认公开及彩蛋专项仍按[后续实施计划](前端整理后续实施计划.md)原分期处理，本批不连带闭环。
