个人角色快捷区局部使用等宽单行网格，不修改 CardActions 的全局换行规则；只按实际可用的动作分列，缺少权限／材质时不保留空按钮。沿用 UiButton 的默认高度与语义色，不把控件缩成图标；完整动作同时写入可访问名称。复用 el-tooltip，在悬浮／聚焦显示提示，提示层不拦截按钮 Enter／Space 的执行。

| 常态文字 | 悬浮／键盘聚焦时的图标 | 完整动作语义 |

三个按钮共享同一 icon-swap 实现，切换时保持等宽单行及按钮尺寸，继续保留完整动作提示与可访问名称；禁用／写入中不播放切换，减少动态效果偏好下即时切换。复用现有动效变量，不恢复旧版整套渐变、阴影或各按钮独立的悬浮逻辑。当前仍为文字加提示，本项仅记录，纳入 3.6.5 按钮能力调整后实施。

**卡片 px 角标规则（本轮追加确认）**：读取原图实际宽高后，仅在能够确认精度不为 1 倍时显示，标准精度、读取中／失败及无法判定的布局不显示角标。皮肤的 64×64 和旧版 64×32 均为 1 倍；披风的 64×32 和裁剪布局 22×17 均为 1 倍。128×128／128×64 皮肤、128×64 披风、44×34 裁剪披风等才显示角标。不能只用图片宽度是否为 64 判定。

角标位于预览右上，容器使用 flex 消除行盒基线偏移，上／右均内缩 8px。曾按卡片 16px 圆角、1px 边框和胶囊 10px 半径计算同心定位为 5px；用户视觉反馈过近，因此采用更宽的等距留白。使用 el-tag `effect="dark"`＋`round` 实心胶囊；仅显示真实图片宽度，例如 `128px`、裁剪高清披风的 `44px`，不写等效画布宽度、不加尺寸／倍数悬浮提示。详情保留实际 px 展示，不受“仅非标准”的卡片条件限制。模型标签统一 el-tag 的 `light`＋`round`；Alex／Steve 为蓝色、披风为绿色，除颜色和文字外使用相同外观，无新增装饰 CSS。

模型、px、正版标签由原 `small`（20px 高）调为大一号 `default`（24px 高），文字统一粗体；不使用 `large`，也不额外手写字号。正版卡片角标与详情复用 `OfficialBindingTag`，绿色 `success`＋`dark` 实心胶囊；卡片位置沿用 px 的 8px 等距留白，仅在拥有读取能力且绑定数据成功加载、确认有绑定时显示。加载中／失败／无权限不显示过期正版角标，详情保留对应读取状态。

精度判断参考本项目材质接收规则及 [skinview-utils 的缩放计算](https://github.com/bs-community/skinview-utils/blob/master/src/process.ts)：裁剪布局改变画布大小，不意味着像素密度改变。后台接受范围与渲染器识别范围仍不完全相同，本轮不改后端格式验证。

## 5 Hash 与 UUID 的查看和复制

默认显示具名字段及原值前 **8 个字符＋三个英文句点**，例如 `皮肤 Hash：b6e5ac15...`。不拼首尾；短于或等于 8 字符不伪造省略。

| 入口 | 行为 |
| --- | --- |
| 悬浮／聚焦摘要 | 显示完整值浮层。 |
| 点击摘要 | 显式打开并保留同一浮层，供触屏查看；此时不复制。 |
| 点击浮层中的完整值 | 复制对应字段的完整原始值；键盘 Enter／Space 等价。简短提示“点击复制”与全文共用一个复制入口，点击提示文字也复制完整原值；成功显示“已复制”。 |
| 点击外部／Esc | 仅关闭标识符浮层，焦点返回触发入口，不穿透关闭详情。 |

浮层复用 Element Plus 现有组件与默认外观；可停留、选中文本、按窄屏宽度折行。复制失败保留全文供手动复制；不复制字段名、省略号或装饰空格，不隐式更改 UUID 格式。未绑定显示普通“未绑定”，读取中／失败不得伪装成未绑定。

用户希望摘要及完整值加虚线下划线提示交互，但当前没有现成的虚线文字样式。Tailwind 的 `underline decoration-dashed` 无须新增手写 CSS，仍属于新增视觉规则。因此按允许降级的约定，**本批默认复用 UiButton 的 tertiary 文字外观及已有悬浮／焦点反馈**，由摘要和完整值本身承载动作；不加额外“展开／复制”按钮、箭头、图标或专用装饰样式。虚线下划线不是本批验收必需项。

## 6 保存 关闭与异步保护

完整逐操作表与保护状态表统一维护在[交互专题第 4—5 节](五类详情交互边界与权限方案.md#4-各操作的建议提交与确认规则)。名称编辑、草稿阻止其他写入、写入中禁止关闭／切换及退出层级已接受；其他操作确认强度与尚未确认的异常策略继续待审。

已确认名称草稿阻止其他写操作、写入中禁止关闭和切换；名称按需编辑／显式保存方案也已获同意：点击名称或编辑入口才显示保存／取消，失焦保持草稿，保存或 Enter 提交，取消仅退出本字段。它不将整个详情改成统一保存，也不影响站点设置等原有组级保存。用户本轮已接受专题第 5.1 节退出对照：显式取消／X 放弃所属范围，遮罩／外层 Esc 有草稿时确认，内层 Esc 不穿透；已有服务器修改不回滚。其他操作的确认强度仍待审，写失败、超时结果不明与写成功但刷新失败分别反馈。

防串记录、正确对象和真实结果属于本批正确性；全站读取架构仍留阶段 4，不借本批宣称已解决跨用户并发覆盖。

## 7 必须继承的业务事实

### 7.1 权限

### 7.2 删除与材质归属

清绑定不删材质，删除角色保留衣柜；个人删除可能按库原上传者分流，管理下架保留角色绑定、头像及文件。准确影响与限制统一见[交互专题第 7 节](五类详情交互边界与权限方案.md#7-后端契约限制与单列问题)，归属完善继续由 [Issue 22](https://github.com/water2004/element-skin/issues/22) 独立跟踪。本批不拆出实际同接口的虚假移除／删除按钮。

### 7.3 正版绑定

总体方向仍为“手动同步、本地可编辑”：本地操作不自动回写远端，解除关联保留本站角色；同步可能覆盖材质及模型，采用接口实际结果。信息与动作清单见第 4 节，具体覆盖确认、解除／删除后果及操作保护见[交互专题](五类详情交互边界与权限方案.md)，仍待逐项审查。

## 10 阶段 4 读取状态与刷新入口

阶段 4 先统一生命周期，再裁剪冗余入口：区分首次未取得结果、已确认空态、已有内容更新、失败；更新时保留可用内容和稳定布局，失败不伪装成空结果。统一参数变化、去重、取消、响应顺序、缓存失效、后台更新及操作后取数，不在页面散布另一套定时器。

优先处理已登记的通知空态消失、个人第三方应用开发者区及已授权区刷新收缩／临时内部滚动条。管理材质的大块亮骨架问题已由 3.5 处理，不再推广该骨架；按钮本身呈现先由 3.6.5 处理。

| 页面／区域 | 最终刷新入口方向 |
| --- | --- |
| 站点、邮件、彩蛋配置 | 保留“重新加载配置”，明确覆盖草稿；有未保存内容先确认，失败组保留输入与基线，不因回到前台自动覆盖。 |
| 通知中心 | 保留局部“更新通知”，保持筛选与有效详情。 |
| 管理列表与第三方应用 | 保留明确范围的更新入口，资源区独立反馈。 |
| 个人应用开发者区 | 保留“更新状态”，用于查看外部审核变化。 |
| 个人应用已授权区 | 补齐进入／返回／撤销成功／外部授权返回后的更新及失败重试，再移除常驻刷新。 |
| 仪表盘 Fallback 状态 | 沿用自动更新及失败重试，再移除重复手动刷新；读取状态不是触发后端立即健康探测。 |
| 公共库、个人角色、衣柜 | 维持无常驻刷新按钮，保证进入、参数变化和操作后的更新。 |

浏览器刷新保留整页初始化能力及适用的原生离开提示，不新增站内 location.reload 按钮，也不替代有明确草稿语义的配置重载。过期阈值和后台更新策略在阶段 4 统一确定；这些入口不得先删后补更新路径。

### 12.7 浮层右侧滚动槽补正（2026-10-27）

用户反馈衣柜材质详情打开后，最右侧仍有未被遮罩覆盖的白条。本次与此前 Element Plus 重复扣宽分开处理：操作页根视口的 `scrollbar-gutter: stable` 在锁滚动后仍保留空槽，其背景由根页面绘制；现有 fixed 浮层未覆盖这一区域。[CSS Overflow 的滚动槽定义](https://drafts.csswg.org/css-overflow-3/#scrollbar-gutter-property) 说明根元素的该属性应用于视口，空槽按 padding 背景延伸绘制。

仅在 body 存在 Dialog／Drawer、MessageBox、ImageViewer 的既有锁定类时，视口改为 `auto`，将同一份 `stable` 预留移入已有 AppShell，并设置 `overflow: hidden`。这样内容继续保留浏览器原生槽宽，浮层则覆盖完整视口；首页原有 AppShell 预留沿用，不重复叠加。最后一个锁定类移除后恢复操作页根视口预留。保留 body 宽度补偿覆盖和组件库的锁定／恢复，不计算像素宽度，不改变普通页面滚动主体，不新增锁定状态或观察器。

回归扩展覆盖深浅主题的四类真实浮层、嵌套关闭与不溢出页面，以及首页／操作页在已有导航断点两侧的锁定前后样式与导航状态，相关 **40 项回归通过**。完整前端 **64 个文件、776 项测试通过**，`npm run build`（含类型检查）、本批源码 Prettier／ESLint 及 `git diff --check` 通过。CSSOM 断言用于核对预留所属层级及恢复，不等同真实浏览器像素测量。以下为用户补填的通过记录，已纳入本轮闭环。
