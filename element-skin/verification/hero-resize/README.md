# Issue #19 首页背景缩放验证用例

验证 PR #21 修复后的实际首页。包含已构建的前端、合成图片和全景素材，以及仅监听
`127.0.0.1` 的本地服务。无需仓库、npm install、数据库、Redis 或真实账号。
页面使用原有 `HomeView`、布局与 `createHeroScene`，保持浏览器真实动画时钟。

## 下载和启动

在 PR 最新一次成功的 **Frontend quality** Actions 运行页面底部，
下载 **issue-19-verification** artifact 并完整解压。下载 artifact 需要登录 GitHub；
保留期为 30 天，过期后可按下文重新构建。

安装 Node.js 24，在解压目录打开终端：

```powershell
node server.mjs
```

打开 <http://127.0.0.1:5174/__verify/>。保持终端运行，结束后按 `Ctrl+C` 停止。
Windows PowerShell 7 也可运行 `./start.ps1`。
端口被占用时运行 `node server.mjs --port 5175`，打开对应端口的地址。

`build-info.json` 记录构建提交 SHA 与时间，可与 Actions 的 checkout 提交核对。
本用例只提供首页展示所需接口；登录、注册、个人面板等业务操作不在验证范围。
“模拟登录”仅切换本地合成账号，不创建账号或凭据。

## 操作与精确预期

| 编号   | 操作                                                                                                       | 预期                                                                                                     |
| ------ | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| V19-01 | 单张图片，分别选择浅色、深色；拖动宽度滑块，并连续缩放至少 10 秒                                           | 背景始终覆盖可视区域，无瞬间白屏、黑屏、透明空帧或旧尺寸边缘；图片保持等比裁切                           |
| V19-02 | 旋转全景，分别选择浅色、深色；连续缩放至少 10 秒                                                           | 背景不中断，全景旋转连续，不因缩放回到起始角度                                                           |
| V19-03 | 图片 + 全景轮播，分别选择浅色、深色；连续缩放至少 25 秒                                                    | 依次出现日间图片、暮色图片、全景；缩放不会重置 6 秒轮播计时或淡入淡出进度                                |
| V19-04 | 停止连续缩放；依次点击“桌面”和“窄屏”；分别勾选、取消“模拟登录”                                             | 未登录显示“登录账号”“即刻注册”，模拟登录显示“进入个人面板”；按钮保持 fixed，玻璃模糊、标题、页脚布局正常 |
| V19-05 | 点击“打开独立首页”，拖动真实浏览器窗口边缘、最大化/还原，改变浏览器缩放比例；有条件时跨不同 DPI 显示器移动 | 图片、全景、轮播均不中断；背景尺寸跟随视口，中心按钮和页脚无错位                                         |

切换素材、主题、模拟登录会重新载入首页，这是用例控制操作；拖动宽度和连续缩放不重新载入。
“窄屏”为 `390 × 844` 的 iframe 视口，不等于真实移动设备验收。
可用独立首页在本机不同浏览器重复验证；服务不对局域网开放。

## 从源码重新构建

在本 PR 分支的 `element-skin` 目录运行（Node.js 24）：

```powershell
npm install --no-package-lock
npm run build:verification
node verification/hero-resize/dist/server.mjs
```

输出目录 `verification/hero-resize/dist` 就是可分发的包。
构建脚本复用当前前端 Vite 配置，仅将入口替换为用例初始化入口，
强制使用本地 API，并关闭 `.env` 文件加载。验证代码不会进入正常生产构建。
`npm run test:browser` 会先构建此包，再同时验证原有渲染场景与可分发首页。
