## 用户人工验收清单

入口：`http://localhost:5173/`，使用普通产品页面；不要使用 `.cache` 诊断页。桌面建议 1440×900，手机建议 390×844；窄屏重点补查 320×568。分别使用已登录与未登录会话，未登录可以使用独立隐私窗口，避免退出现有会话。主题相关项目覆盖深、浅两种主题。

以下每项只有用户实际检查通过后才能勾选。静态截图不能单独确认动画是否正常。

- [ ] **新增：刷新最初几帧闪屏**：首页 `/` 与仪表盘 `/dashboard/home`，分别在浅色和深色下直接刷新；检查内容出现前是否闪过另一种底色，仪表盘是否先呈现首页的临时布局。用户已报告该项有问题，待修复后由用户复验。

- [ ] **首页刷新入场（桌面／手机，已登录／未登录）**：直接刷新首页，检查标题、副标题渐入；按钮整体上移且文字同步渐入。按钮文字不应瞬间先出现，也不应晚于按钮单独跳动；毛玻璃从按钮出现时可见，范围始终限于圆角按钮。
- [ ] **首页站内返回（同上四种组合）**：进入其他页面再返回首页，与刷新时比较；入场方向、时长和最终位置一致，不出现额外二次位移。
- [ ] **首页按钮宽度**：已登录为居中的单按钮，未登录为两个紧凑按钮；在 320／390／768／769px 附近检查，不突然铺满、折行或被裁切。参考既有设计：个人面板按钮约 170×52px，匿名按钮窄屏约 112×52px、桌面约 148×52px。
- [ ] **首页悬停与焦点**：桌面反复移入／移出按钮，轻微上浮，无细描边闪烁、毛玻璃越界或额外阴影；键盘焦点提示可见。
- [ ] **首页壳、footer 与预留滚动区域**：标题、按钮、footer 不重叠，手机横屏仍可见关键入口；右侧无白色竖条，背景没有随内容产生错位或不合理滚动。
- [ ] **顶栏刷新加载**：刷新首页及通知页，留意通知、主题、头像／用户名的出现顺序；操作整组出现，不先出现主题按钮再横移；头像加载和通知红点出现不挤动其他图标。未登录时不闪现头像或通知入口，已登录时不闪现登录／注册。
- [ ] **顶栏页面切换**：首页 → 通知页 → 个人资料 → 点击站名回首页，反复两轮；检查图标位置、间距和顶栏高度，不出现意外左移或上下跳动。首页与标准页允许颜色变化。
- [ ] **账户菜单跳转专项**：首页点击通知入口 → 打开头像菜单 → 点击“个人资料”，再回首页重复。应一次点击到达目标页，无菜单停留但页面不动的情况。此前自动浏览器偶发未跳转，组件回归测试未复现；此项仍待真人确认，不能据测试通过直接关闭。
- [ ] **主题切换**：首页及标准页各切换深浅主题；图标可更换、颜色可过渡，操作区不发生位置或宽度跳变。
- [ ] **导航响应式**：桌面逐渐缩窄到手机再放大；空间不足时桌面导航隐藏，站名和右侧操作不重叠；放大后导航自动恢复。窄屏页面没有横向滚动条。
- [ ] **抽屉与弹窗**：手机开关导航抽屉，桌面打开“重设邮箱”后取消；顶栏和正文不因滚动锁定横向跳动，关闭后滚动恢复。无需提交邮箱修改。
- [ ] **认证页来回切换**：打开登录、注册、重置密码后返回首页；认证页按既有设计隐藏顶栏和 footer，返回后顶栏、导航重新出现，无残留空位。长注册表单在 320px 下可从顶部滚动到底部。
- [ ] **邮箱域名选择框**：注册页与重设邮箱弹窗中，域名已有默认选中值，输入组外边框连贯，无内部套框；域名可展开选择，不能键入搜索文字，左侧邮箱前缀仍可编辑；方向键和回车可选择。
- [ ] **重置密码与 OAuth 页面**：按本地配置检查可达页面的卡片、内边距、长文本、错误提示和操作区；验证码窄屏分行，设备代码完整，底部入口可滚动到达，无横向溢出。若当前配置不允许看到完整内容，记录为“不可达／待验”，不要记通过；无需发送邮件、修改密码或批准／拒绝授权。
